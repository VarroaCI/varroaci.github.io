# varroa-site

The public brochure + docs site for Varroa (https://varroa.dev): a hand-authored
brochure (`/`, `/compare`) plus a Starlight-rendered copy of the operator
handbook (`../docs/`) under `/docs/`.

Everything under `src/content/docs/` and `public/docs-examples/` is generated by
`scripts/sync-docs.mjs` at build time: edit the handbook under `docs/`, never the
generated copies. `npm run build` is the gate and runs the docs sync, the prose
check, link validation, and the brochure section-order check.

This is its own npm project — Node 22 LTS, Astro + Starlight — and is never
part of the Go build or the `frontend/` build.

## Develop

```bash
cd site
npm ci
npm run dev
```

`predev`/`prebuild` regenerate `src/content/docs/docs/**` and
`public/docs-examples/**` from `../docs/` (via `scripts/sync-docs.mjs`) and
`src/data/compare.generated.json` from `src/data/compare.yaml` (via
`scripts/validate-compare.mjs`) before every dev server start or build. Both
outputs are git-ignored — never hand-edit them, edit `../docs/` or
`src/data/compare.yaml` instead.

## Build

```bash
cd site
npm ci
npm run build
```

Exits non-zero on: a docs page missing its leading `# H1`; an unresolved or
disallowed-escaping relative link in `../docs/`; a broken internal link or
anchor (`starlight-links-validator`); an invalid `compare.yaml` row. Static
output lands in `site/dist/`.

## Test

```bash
cd site
npm test
```

(`node --test scripts/*.test.mjs` under the hood — the installed Node no
longer auto-discovers test files from a bare directory argument to
`--test`, so the glob is explicit.)
